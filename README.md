## 哪些人该买，哪些人装了也是吃灰

Paletro 只做一件事：按下 ⇧⌘P，把当前 App 菜单栏里的所有命令拉成一个列表，模糊搜索，回车执行。它把 VS Code 和 Sublime 那种命令面板搬到了所有 App 上。

该买的人有这么几类。常用软件菜单项特别多的，典型是 Adobe 全家桶、Final Cut Pro、Xcode、Sketch，这些软件的功能藏在三五层菜单里，快捷键又多又难记。手上软件换着用、每套快捷键体系都不一样的人，脑子记不过来，直接搜命令名更快。还有一类是从 IDE 转过来、已经习惯命令面板操作的人，肌肉记忆改不掉。

不适合的人，说实话比适合的还多。日常主力是 Pages、Numbers 这类 iWork 软件，或者 Apple Music、Affinity 系列，MacUpdate 上有用户明确反馈这些 App 的菜单读不到，买了也用不上。已经装了 Raycast 并且用得顺手的，先别急着付钱，Raycast 自带搜索菜单项的命令，免费版就能用，虽然它不做按 App 的菜单排除规则，覆盖日常够用了。一年也用不了几次菜单命令的人同样不必买，这工具的价值跟使用频率成正比，低频用户感觉不到差别。

把同类工具摆一起看更清楚。Raycast 是全能型，菜单搜索只是它几十个功能里的一个，免费可用，优势是不用再装一个 App。Alfred 要做同样的事得装第三方 workflow，而且得先买 Powerpack，适合已经深度使用 Alfred 的人。Keyboard Maestro 是自动化工具，菜单项操作只是它顺带能做的一件事，搭建成本和学习成本都高出一个量级。

Paletro 的差异在专注。它能按 App 设规则，排除掉某些永远用不到的菜单项，或者在特定 App 里直接禁用；非英文系统下可以用英文单词搜到菜单项，部分 App 支持；搜索结果里会显示原软件的快捷键，用它当快捷键提示器也行。这些细节只有天天用才体会得到，偶尔用一次的人感受不到。👉 [对照一下自己的常用 App 再下单](https://lizhi.shop/products/paletro?cid=7bbix2xj)

## 常见问题

**Paletro 是买断还是订阅？**
买断。6.99 美元一次性付费，没有月付年付，也不会自动续费。

**有免费试用吗？**
有，14 天，功能完整。

**为什么有些 App 里搜不到命令？**
它靠 macOS 辅助功能读当前 App 的菜单栏。菜单结构不标准，或者没把菜单暴露给辅助功能的 App，就读不到。这也是试用期最该测的东西。

**现在有 Paletro 优惠码吗？**
没有公开码。能叠加的只有荔枝商店的新用户首单券和会员券，结算时自动抵扣，不用填。

**支持哪些 macOS 版本？**
官方标注 macOS 10.14 或更高。系统太老的话，新版本能不能装要看商品页说明。

**和 Raycast 的菜单搜索有什么不同？**
Raycast 内置菜单搜索，免费，但功能单一、不能按 App 精细排除；Paletro 只做这一件事，多了 App 规则、原快捷键显示和非英文系统下的英文搜索。
